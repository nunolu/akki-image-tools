# Microsoft Store listing draft: Akki Image Tools 1.4.0

## What's new

- Open HEIC and HEIF images for conversion.
- Export multiple image widths in one batch and start quickly with built-in presets.
- Choose custom crop ratios and select from nine crop positions; add padding when needed.
- Browse images with a small preview cache and next-image preload.
- Inspect basic image metadata and choose JPEG metadata options.
- Optionally keep colour profiles when removing metadata from supported output formats.

The JPEG EXIF GPS-only option does not remove location from XMP, IPTC, maker notes or other sources. Images and filenames can also reveal location.

## Description

Akki Image Tools is a Windows app for converting and preparing images locally. Add files or folders, choose an output format, and resize, crop, rotate, flip or watermark images in batches. Compare the original and converted image before saving, and use presets for settings you use often.

Supported output formats include WebP, JPEG, PNG, AVIF, TIFF, BMP and ICO. The app can read HEIC and HEIF images. Your images stay on your PC and originals are preserved.
